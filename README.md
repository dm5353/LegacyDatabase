# Лабораторная работа №9. Базы данных.

&nbsp;&nbsp;&nbsp;&nbsp;Продолжая тему хранения данных, следует перейти к такому важному варианту, как базы данных. С помощью баз данных можно организовать упорядоченное хранение и выборку больших объемов структурированных данных. Это могут быть логи событий, история покупок, товары для витрины магазина или даже таблица рекордов. В Android для этих целей имеется встроенная реляционная СУБД SQLite.
